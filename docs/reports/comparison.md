# Sim vs published anchors

> Preserved M4 comparison. `tv-sim validate --out reports` writes a fresh
> `reports/comparison.md` beside regenerated metrics and images.

Generated by `python3 -m tv_sim validate`. The four `generic_*` profiles are placeholders, not emulations of the reviewed sets.

Numbers in the Published column are transcribed from `docs/research/m4-reference-ranges.md`. An envelope is `in` when the simulator value is inside those bounds, inclusive. A single published sample is `in` when the simulator is within 5% relative. That percentage is a project scoring rule, not a publisher tolerance. `NR` means the research note has no numeric value for that protocol, or the only cited figure is a different device class and is not scored. `out` means a numeric reference was scored and the simulator missed it. `undefined` is a simulator black at or below the reporting floor (no finite contrast).
